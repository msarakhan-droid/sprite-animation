# Завдання 4 — Зображення, спрайти, спрайтшити та простий UI

Це навчальна демонстрація анімації персонажа, створена як **варіант А (без зовнішніх файлів)** на HTML, CSS і JavaScript. Графіка персонажа генерується засобами Canvas, тому окремі PNG-файли або бібліотеки не потрібні. Клавіша **1** вмикає анімацію стояння (6 FPS), **2** — ходьбу (11 FPS), **3** — біг (15 FPS). Кожна анімація має власні пози рук і ніг, а рух циклічно перемикається за часовим інтервалом. Повзунок змінює масштаб від 60% до 180%, а кнопка **Flip** розвертає персонажа горизонтально. Пунктирна рамка показує hitbox, який має окремі розміри для кожного стану та масштабується разом із персонажем. Для запуску достатньо відкрити `index.html` у браузері або опублікувати репозиторій через GitHub Pages.

## Керування

- **1** — стояти (6 FPS)
- **2** — ходити (11 FPS)
- **3** — бігти (15 FPS)
- **Flip** — змінити напрямок
- **Масштаб** — змінити розмір персонажа
- **Показувати hitbox** — показати або приховати рамку зіткнення

## Технічні деталі

- Формат: один HTML-файл із Canvas 2D, CSS і JavaScript.
- Розмір Canvas: 800 × 450 пікселів, адаптивно відображається на сторінці.
- FPS анімації: 6 / 11 / 15 залежно від стану; `requestAnimationFrame` використовується для малювання, а зміна кадру прив'язана до часу.
- Hitbox: Idle 76×168, Walk 92×168, Run 112×163 (логічні одиниці до масштабування).
- Покращення: додати окремі PNG-спрайти, більше станів і перевірку зіткнень з об'єктами сцени.

> Примітка: персонаж намальований програмно, а не з PNG-спрайтшита. Це відповідає ідеї варіанта без зовнішніх файлів, але якщо викладач вимагає саме кадри зі спрайтшита, знадобиться додаткова реалізація.
